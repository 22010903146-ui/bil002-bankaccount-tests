# Yürütme kanıtlarının kapsamı

Yerel kişisel çalışma dizini yolları taşınabilirlik için WORKSPACE ile değiştirilmiştir. Test sayıları, HTTP yanıtları, ölçümler ve zaman damgaları korunmuştur.

Önceki GitHub yayını kaldırılmıştır. Önceki CI JSON/log dosyaları arşiv kanıtıdır; yeni yayının CI sonuçları ayrıca kaydedilir. TDD kaynak değişiklikleri özgün sırayla korunmuştur; rapor taslakları kaynak geçmişinden ayrıldığı için commit kimlikleri yeniden hesaplanmıştır.
